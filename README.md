# StarCat Add-on Generator for GitHub Pages

Este repositório contém uma aplicação web estática desenvolvida para criar add-ons do Minecraft Bedrock Edition diretamente pelo navegador (inclusive no celular) e exportar o arquivo `.mcaddon` pronto com as pastas `Behavior_Pack` e `Resource_Pack` estruturadas corretamente.

## Como publicar no GitHub Pages:
1. Crie um repositório público no GitHub.
2. Envie todos estes arquivos (`index.html`, `bloco.html`, `item.html`, `script.html`, `mob.html`, `style.css`, `builder.js`) para a branch `main`.
3. Vá em **Settings > Pages** no seu repositório.
4. Em **Branch**, selecione `main` e `/ (root)`, clique em **Save**.
5. Acesse o link fornecido pelo GitHub Pages e comece a criar seus add-ons!
